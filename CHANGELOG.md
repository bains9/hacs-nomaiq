# Changelog

## 2.1.0

- Add NOMA iQ smart ceiling-fan support.
- Add independent fan and light entities.
- Add fan speed and direction controls.
- Add light brightness control through `light_rating`.
- Add five-step colour-temperature control through `light_color_index`.
- Map the five native warmth positions to 2700–6500 K for the standard Home Assistant UI.
